# Third-party icons

Application actions use Microsoft Fluent UI System Icons, Regular 24, version 1.1.344, commit `a347af95478f989038cccbf085978865264c048a`, under the MIT license. The set covers navigation, audio, media, keyboard, capture and controllers. Xbox Controller Regular 24 identifies Xbox devices; Games Regular 24 provides the generic fallback.

Input hints use [Kenney Input Prompts](https://kenney.nl/assets/input-prompts), version 1.5A, under CC0. Original Xbox, keyboard and mouse SVGs and the original license are retained in `Assets/Icons/input-*.svg` and `input-prompts-license.txt`. The provenance manifest records every archive path and SVG hash, and pins the archive SHA-256. `InputGlyphs.xaml` preserves the source paths. Optical bounds give prompts a consistent height; semantic colors follow the current theme. Screen readers receive complete command names. These symbols identify controls and do not imply affiliation with their manufacturers.

Steam uses the Simple Icons vector at commit `c71c69e3a27e4436936b831c72643e6513b9f49b`. The project distributes it under CC0; its Steam entry specifies no separate license and links to [Valve branding guidelines](https://partner.steamgames.com/doc/marketing/branding). Steam and its marks belong to Valve.

Playnite uses the official monochrome symbol from `JosefNemec/Playnite`, `media/playnite-logo-white.svg`, commit `3e8abb241873e326e27c75b59dd0d2ea367698e3`, under the MIT license. The original SVG and license remain in `Assets/Icons/playnite.svg` and `playnite-license.txt`. The complete path uses nonzero fill; only scale and theme color change. Playnite and its mark belong to their respective owners.

Original SVGs, licenses, source URLs, revisions and SHA-256 hashes are recorded in `Assets/Icons/provenance.json` and adjacent files. `steam-metadata.json` retains the inspected individual entry. `Icons.xaml` preserves source coordinates and fill rules. `VectorIcon` retains the original 24x24 frame for Fluent icons and 1024x1024 frame for Playnite. Input prompts use their explicit optical bounds. No SVG renderer or network download is required at runtime.

The executable and tray icon derive from Microsoft Games Regular 24, preserving its path, with a light foreground and two green surfaces authored for this project. Source and attribution remain in `Assets/overlay-controller.svg` and `Assets/overlay-provenance.json`, with the full MIT license in `Assets/Icons/fluent-license.txt`. The embedded ICO includes 16/20/24/32/48/64/128/256 px images with alpha. WPF rendering is a preparation tool and is not part of the product.
